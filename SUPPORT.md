# Support

Use GitHub Discussions for integration questions and conceptual design. Use
issues for reproducible defects, accepted roadmap work, and protocol proposals.
Use private vulnerability reporting for security-sensitive findings.

When requesting help, include:

- package and Node.js versions;
- event-store adapter;
- operation attempted;
- complete error class and code;
- minimal event stream or reproduction;
- whether the stream passes offline lineage verification.

Do not publish production event journals containing sensitive identifiers.
