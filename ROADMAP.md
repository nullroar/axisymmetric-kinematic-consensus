# Roadmap

## 1.1 — Persistence hardening

- atomic SQLite compare-and-append adapter;
- snapshot-aware suffix loading;
- terminal-digest anchoring port;
- stream export and offline verifier.

## 1.2 — Interoperability

- language-neutral conformance corpus;
- JSON Schema validation at ingress;
- Rust replay oracle;
- protocol capability negotiation.

## 1.3 — Distributed operation

- PostgreSQL adapter with serializable append;
- OpenTelemetry trace adapter;
- deterministic command partitioner;
- read-model checkpoint protocol.

## 2.0 research

- multi-axis composition;
- signed authorship envelopes;
- arbitrary rational unit lattices;
- topology-aware discontinuity events;
- zero-knowledge proofs of displacement bounds.

Roadmap entries are intentions, not compatibility commitments. Consensus
changes require a protocol proposal and ADR.
