- Branded fixed-point domain quantities.

- Command decider and deterministic event reducer.
- SHA-256 event lineage and snapshot integrity.
- Optimistic concurrency and command idempotency.
- In-memory and JSONL event-store adapters.
- Prometheus text exposition adapter.
- Operator CLI, examples, verification scripts, and benchmarks.
- Unit, integrity, replay, and generative property tests.
